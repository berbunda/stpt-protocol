# stpt-protocol
Secure Terminal Processing Tools is realisation of remote CLI control via QUIC transport protocol

Specification: `specs/PROTOCOL.md`. Roadmap of the protocol: `docs/ROADMAP.md`.

PE001–PE005 define draft file transfer profile 1; it is not yet implemented in the program. The [Tier PE scenario review](docs/PE_REVIEW.md) records specification checks and remaining implementation validation.
