# Tier RG full scenario review

2026-11-25, program 0.5.0-1, specification draft-61. All 41 PG scenarios were reviewed and mapped to native tests, authenticated Server cases, QUIC fault peers, controlled DNS/quotas and explicit policy inspection. The canonical detailed matrix is in the program repository's docs/RG_REVIEW.md.

Fixed: a cancelled early remote flow could contact the Client target; retained native work could lose the shared Account Budget identity; opening timeout sent FIN rather than TIMEOUT; blocked refusal READY did not observe rule cancellation; foreground forwarding did not run the existing route watcher. Four saved pre-fix regressions demonstrate the first four defects; the watcher omission was found by inspection and covered by a real foreground-runner migration regression. Disallowed ports are rejected before DNS and malformed multiple trailing root dots are refused. No wire allocation or normative requirement changed.

Final Windows: 339 full-suite passes, two skips, with the 61-second RG idle test passed separately. Final Linux: 382 full-suite passes, ten skips, with RG idle and root-only nobody socket-ownership tests passed separately. Remaining skips are existing non-RG tests. Clippy all targets with warnings denied passed on both. Authenticated tests preserve rules across terminal detach/Session termination and enforce shared quota across five Connections. Real default 10-second opening and 61-second idle tests supplement accelerated fault clocks.

Windows Client/Linux Server local, remote and domain SOCKS tests each transferred 200000 bytes with half-close and matching SHA-256. A temporary SSH UDP datagram relay preserved end-to-end STPT QUIC/TLS because direct host-to-VM UDP did not answer; direct-path reachability is not claimed. Tests used disposable identities and did not change firewall/routes. Controlled answer vectors/reservations validate DNS candidate and quota transitions without claiming authoritative DNS-provider attacks or 2048 simultaneously open native sockets. Native resolver/NSS work retains its slot through completion if it outlives protocol cancellation.

The CLI remains one rule per foreground command, policies are read once and restart revokes Connections, Windows uses its current Account/token, and UDP stays PG005/RG005 in the backlog. No later-Tier feature or general network/security certification is claimed.
